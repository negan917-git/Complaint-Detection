Инструкция: получение токена Telegram-бота

  1. Откройте @BotFather в Telegram
  2. Выполните команду /newbot
  3. Создайте бота (укажите имя и username)
  4. Скопируйте полученный Token
  5. Вставьте токен в поле на странице Боты
  6. Нажмите «Подключить»

OpenAI API

Для использования AI-анализа сообщений укажите OPENAI_API_KEY в файле .env. Ключ не передаётся через интерфейс — он считывается сервером из переменной окружения.
